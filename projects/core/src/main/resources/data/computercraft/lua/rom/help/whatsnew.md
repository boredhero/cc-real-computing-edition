New features in CC: Real Computing Edition 1.120.2-rce.0.4.0-SNAPSHOT

* Add persistent computer/turtle UUIDs through os.getComputerUUID() and peripheral getUUID().
* Preserve UUIDs through saves, movement and pickup; assign distinct UUIDs to placed copies.
* Show UUIDs in the id program while keeping numeric IDs compatible.
* Increase computer terminals to 61x23 by default and turtle terminals to 47x16, with scaled UI input.
