New features in CC: Real Computing Edition 1.120.2-rce.0.6.0-SNAPSHOT

* Observe visible entities with UUIDs and react to entity movement/data changes.
* Add turtle.attackEntity, useEntity and collectEntity with visibility and protection checks.
* Add optional face and sneak settings to targeted block interactions.
* Add inspectInventoryAt, pushItemsAt and pullItemsAt through normal container menus.
* Add tick-driven useItem charging, isUsingItem and cancelItemUse, with turtle_item_use completion events.
* Respect cancelled entity interactions without falling through, and report denied attacks as failures.
