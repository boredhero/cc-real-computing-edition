New features in CC: Real Computing Edition 1.120.2-rce.0.5.0-SNAPSHOT

* Add persistent pocket computer UUIDs and separate active copies from their originals.
* Add UUID rednet send, lookupUUID and broadcastUUID, including repeater support.
* Migrate internal computer files to UUID directories without removing legacy files.
* Give recognised clones independent copies of their source computer's files.
* Update computer-folder links to open UUID storage. See the fork's identity guide for migration details.
